1. INTRODUCTION                                             *gemi-introduction*

Gemi.nvim provides seamless integration with Google's gemini-cli, allowing
you to interact with Gemini AI directly from Neovim. The plugin features a
toggleable overlay with prompt input, logs, and file change tracking.

Features:
- Easy gemini-cli installation and dependency management
- Toggleable overlay UI with conversation context
- Real-time execution with progress feedback
- File change tracking and navigation
- Side-by-side diff viewer
- Built-in Google authentication
- Customizable keybindings

==============================================================================
2. INSTALLATION                                             *gemi-installation*

Using lazy.nvim: >
    {
      'nsalerni/gemi.nvim',
      config = function()
        require('gemi').setup()
      end
    }
<

Using packer.nvim: >
    use {
      'nsalerni/gemi.nvim',
      config = function()
        require('gemi').setup()
      end
    }
<

After installation, run |:GemiInstall| to install dependencies.

3. CONFIGURATION                                           *gemi-configuration*

Configure Gemi.nvim by calling setup() with your options: >

    require('gemi').setup({
      ui = {
        width = 0.8,
        height = 0.8,
        position = 'center',
        border = 'rounded',
        title = ' Gemi ',
        prompt = '> ',
      },
      conversation = {
        max_history_length = 20,
      },
      keymaps = {
        toggle = '<leader>g',
        files = '<leader>gf',
        diff = '<leader>gd',
        stop = '<leader>gs',
        install = '<leader>gi',
        logs = '<leader>gl',
        reload = '<leader>gr',
        model = '<leader>gm',
      },
      gemini = {
        model = 'gemini-2.5-flash',
        debug = false,
        all_files = false,
        yolo = true,
        checkpointing = true,
      },
      tracking = {
        auto_scan = true,
        max_files = 2000,
        max_file_size = 1024 * 1024,
        store_snapshot_content = false,
        exclude_patterns = {
          '%.git/',
          'node_modules/',
          '%.DS_Store',
          '%.log$',
        },
      },
      logging = {
        debug = false,
        level = 'INFO',
        max_entries = 500,
      },
      install = {
        check_node = true,
        node_min_version = '16.0.0',
        auto_install = false,
      },
    })
<

                                                               *gemi-config-ui*
ui.width            Overlay width as a fraction of screen width (0.0 to 1.0)
ui.height           Overlay height as a fraction of screen height (0.0 to 1.0)
ui.position         Overlay position: 'center', 'bottom', or 'top'
ui.border           Border style: 'single', 'double', 'rounded', etc.
ui.title            Window title text
ui.prompt           Prompt prefix shown in the overlay input

                                                    *gemi-config-conversation*
conversation.max_history_length
                    Maximum conversation messages kept in context

                                                         *gemi-config-keymaps*
keymaps.toggle      Keymap to toggle the UI (default: '<leader>g')
keymaps.files       Keymap to show changed files (default: '<leader>gf')
keymaps.diff        Keymap to show diff view (default: '<leader>gd')
keymaps.stop        Keymap to stop execution (default: '<leader>gs')
keymaps.install     Keymap to install/check CLI (default: '<leader>gi')
keymaps.logs        Keymap to show logs (default: '<leader>gl')
keymaps.reload      Keymap to reload changed files (default: '<leader>gr')
keymaps.model       Keymap to switch model (default: '<leader>gm')

                                                           *gemi-config-gemini*
gemini.model        Gemini model to use (default: 'gemini-2.5-flash')
gemini.debug        Pass --debug to gemini-cli
gemini.all_files    Pass --all_files to gemini-cli
gemini.yolo         Pass --yolo to gemini-cli
gemini.checkpointing Pass --checkpointing to gemini-cli

                                                         *gemi-config-tracking*
tracking.auto_scan      Auto-track file changes (default: true)
tracking.max_files      Maximum project files to scan (default: 2000)
tracking.max_file_size  Maximum file bytes to keep for diffs (default: 1048576)
tracking.store_snapshot_content
                    Store full file contents in snapshots (default: false)
tracking.exclude_patterns   File patterns to exclude from tracking

                                                         *gemi-config-logging*
logging.debug         Enable verbose debug logging
logging.level         Minimum log level: DEBUG, INFO, WARN, ERROR
logging.max_entries   Maximum log entries to retain

                                                         *gemi-config-install*
install.check_node        Check Node.js during installation
install.node_min_version  Minimum supported Node.js version
install.auto_install      Auto-install missing dependencies on setup

6. KEYBINDINGS                                               *gemi-keybindings*

Default keybindings (can be customized in configuration):

{mode}  {lhs}           {rhs}                   {description}
n       <leader>g       |gemi.toggle()|        Toggle Gemi overlay
n       <leader>gf      |gemi.show_changed_files()| Show changed files
n       <leader>gd      |gemi.show_diff()|     Show diff view
n       <leader>gs      |gemi.stop()|          Stop execution
n       <leader>gi      |gemi.install_cli()|   Install CLI
n       <leader>gl      |:GemiLogs|            Show logs
n       <leader>gr      |:GemiReload|          Reload changed files
n       <leader>gm      |:GemiModel|           Switch model

Overlay keybindings (when the overlay is open):

{mode}  {lhs}           {description}
n/i     <CR>            Execute the current prompt
i       <S-CR>          Insert a newline in the prompt
n/i     <Tab>           Toggle focus between logs and prompt
i       <C-Tab>         Toggle focus between logs and prompt
n/i     <C-g>           Toggle the overlay
n       r               Refresh the logs panel
n       c               Toggle conversation context
n       x               Clear conversation history
n/i     <Esc>           Close the overlay
n       q               Close the overlay
i       <C-c>           Close the overlay

7. TROUBLESHOOTING                                       *gemi-troubleshooting*

Problem: "gemini-cli not found"
Solution: Run |:GemiInstall| to install dependencies

Problem: "Node.js is not installed"
Solution: Install Node.js from https://nodejs.org/

Problem: Authentication fails
Solution:
- Run `gemini` in your terminal to re-authenticate
- Check internet connection
- Ensure you have a Google account with Gemini access

Problem: No file changes detected
Solution:
- Execute a Gemi command after plugin installation
- Check exclude patterns in configuration
- Verify you're in a project directory

Problem: UI doesn't appear
Solution:
- Check Neovim version (0.8+ required)
- Verify plugin installation
- Check for conflicting keybindings

For more help, visit: https://github.com/nsalerni/gemi.nvim/issues
