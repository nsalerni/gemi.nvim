1. INTRODUCTION                                             *gemi-introduction*

Gemi.nvim provides seamless integration with Google's gemini-cli, allowing
you to interact with Gemini AI directly from Neovim. The plugin features a
minimal, toggleable UI and comprehensive file change tracking.

Features:
- Easy gemini-cli installation and dependency management
- Minimal, non-intrusive UI
- Real-time execution with progress feedback
- File change tracking and navigation
- Side-by-side diff viewer
- Built-in Google authentication
- Customizable keybindings

==============================================================================
2. INSTALLATION                                             *gemi-installation*

Using lazy.nvim: >
    {
      'your-username/gemi.nvim',
      config = function()
        require('gemi').setup()
      end
    }
<

Using packer.nvim: >
    use {
      'your-username/gemi.nvim',
      config = function()
        require('gemi').setup()
      end
    }
<

After installation, run |:GemiInstall| to install dependencies.

3. CONFIGURATION                                           *gemi-configuration*

Configure Gemi.nvim by calling setup() with your options: >

    require('gemi').setup({
      ui = {
        width = 0.8,
        height = 1,
        position = 'bottom',
        border = 'rounded',
        title = ' Gemi ',
        prompt = 'Gemi: ',
      },
      keymaps = {
        toggle = '<leader>g',
        files = '<leader>gf',
        diff = '<leader>gd',
        stop = '<leader>gs',
        install = '<leader>gi',
        logs = '<leader>gl',
        reload = '<leader>gr',
        model = '<leader>gm',
      },
      gemini = {
        model = 'gemini-2.5-flash',
        debug = false,
        all_files = false,
        yolo = true,
        checkpointing = true,
      },
      tracking = {
        auto_scan = true,
        max_files = 2000,
        max_file_size = 1024 * 1024,
        exclude_patterns = {
          '%.git/',
          'node_modules/',
          '%.DS_Store',
          '%.log$',
        },
      },
    })
<

                                                               *gemi-config-ui*
ui.width            Width of the prompt window (0.0 to 1.0)
ui.height           Height of the prompt window (lines)
ui.position         Position: 'bottom', 'top', or 'center'
ui.border           Border style: 'single', 'double', 'rounded', etc.
ui.title            Window title text
ui.prompt           Prompt text shown in input

                                                         *gemi-config-keymaps*
keymaps.toggle      Keymap to toggle the UI (default: '<leader>g')
keymaps.files       Keymap to show changed files (default: '<leader>gf')
keymaps.diff        Keymap to show diff view (default: '<leader>gd')
keymaps.stop        Keymap to stop execution (default: '<leader>gs')
keymaps.install     Keymap to install/check CLI (default: '<leader>gi')
keymaps.logs        Keymap to show logs (default: '<leader>gl')
keymaps.reload      Keymap to reload changed files (default: '<leader>gr')
keymaps.model       Keymap to switch model (default: '<leader>gm')

                                                           *gemi-config-gemini*
gemini.model        Gemini model to use (default: 'gemini-2.5-flash')
gemini.debug        Pass --debug to gemini-cli
gemini.all_files    Pass --all_files to gemini-cli
gemini.yolo         Pass --yolo to gemini-cli
gemini.checkpointing Pass --checkpointing to gemini-cli

                                                         *gemi-config-tracking*
tracking.auto_scan      Auto-track file changes (default: true)
tracking.max_files      Maximum project files to scan (default: 2000)
tracking.max_file_size  Maximum file bytes to keep for diffs (default: 1048576)
tracking.exclude_patterns   File patterns to exclude from tracking

7. TROUBLESHOOTING                                       *gemi-troubleshooting*

Problem: "gemini-cli not found"
Solution: Run |:GemiInstall| to install dependencies

Problem: "Node.js is not installed"
Solution: Install Node.js from https://nodejs.org/

Problem: Authentication fails
Solution:
- Run `gemini` in your terminal to re-authenticate
- Check internet connection
- Ensure you have a Google account with Gemini access

Problem: No file changes detected
Solution:
- Execute a Gemi command after plugin installation
- Check exclude patterns in configuration
- Verify you're in a project directory

Problem: UI doesn't appear
Solution:
- Check Neovim version (0.8+ required)
- Verify plugin installation
- Check for conflicting keybindings

For more help, visit: https://github.com/your-username/gemi.nvim/issues
